# Everlight Group website

Static site (HTML, CSS, JS). Upload the contents of this folder to the web root of everlightindia.com.

Files: index.html, about.html, services.html, contact.html, 404.html, css/style.css, js/main.js, js/home.js, js/contact.js, images/, robots.txt, sitemap.xml, site.webmanifest, favicon.ico, .htaccess (Apache only).

SEO included: unique titles and descriptions, canonical URLs, Open Graph and Twitter cards, JSON-LD (Organization, WebSite, AboutPage, ContactPage, ItemList, BreadcrumbList), sitemap, robots.txt, favicons, manifest, image dimensions and lazy loading, semantic landmarks, one h1 per page.
